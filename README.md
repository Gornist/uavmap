# uavmap

Гражданская карта радиовидимости для пилотов дронов: насколько далеко можно улететь с учётом рельефа, на каких частотах и на какой высоте связь будет держаться.

> **Статус: в разработке.** Ядро расчёта готово, интерфейс собирается. Сборка пока не проходит.

## Что умеет (и будет уметь)

- **Связь до прицела.** Ставите пульт (точка А), двигаете карту, и прицел показывает расстояние, азимут, запас линии в дБ и наличие прямой видимости.
- **Профиль трассы:** рельеф с учётом кривизны Земли, линия визирования, первая зона Френеля и её 60 %, препятствия.
- **Сравнение высот и аппаратуры:** запас связи на разных высотах дрона и для разных пресетов (ELRS 2.4 ГГц / 868 МГц, Crossfire, LoRa 433, видео 5.8 / 1.2 ГГц и др.), минимальная высота для связи.
- **Зона покрытия:** карта запаса связи вокруг пульта для заданной высоты дрона и карта минимальной высоты полёта, плюс дальность до первого обрыва по азимутам.
- **Где встать пилоту:** подбор точки рядом, откуда лучше связь с районом полёта.
- **Режимы высоты:** над точкой взлёта (как в полётных контроллерах) или над рельефом.
- Карта: спутник, топо, схема, подписи и дороги, отмывка рельефа. Координаты WGS-84 и СК-42 (Гаусс–Крюгер).
- Метки, маршруты, линейка, импорт и экспорт GeoJSON / GPX / KML. Все данные хранятся только на устройстве.

## Модель расчёта

- Потери в свободном пространстве: `FSPL = 32.45 + 20·lg(d, км) + 20·lg(f, МГц)`.
- Дифракция на рельефе по ITU-R P.526: клиновидные препятствия, метод Дейгу (до 3 клиньев) для профиля. В зоне покрытия учитывается главное препятствие луча.
- Эквивалентный радиус Земли `k·R`, по умолчанию `k = 4/3`.
- Запас = `Pпрд + Gпрд + Gпрм − потери − FSPL − дифракция − чувствительность`.

Лес, здания, помехи и диаграммы направленности антенн не моделируются: для них задаются ручные «потери на местности». Значения пресетов ориентировочные, подставьте паспортные данные своей аппаратуры. Результат — оценка для планирования, а не гарантия связи.

## Запуск

```bash
npm install
npm run dev
```

## Данные

- Рельеф: [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (AWS Open Data; SRTM, GMTED, ETOPO1 и др.).
- Подложки: Esri World Imagery, OpenTopoMap (CC-BY-SA), OpenStreetMap. Соблюдайте условия использования провайдеров тайлов.

## Стек

TypeScript, Vite, MapLibre GL JS, proj4.
